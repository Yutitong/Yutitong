# ボクセル押し出し

世界をボクセルの「ディスプレイ」として扱う、オープンワールドの 3D ゲームの試作です。
キャラも木箱も、なめらかに動くのではなく、ボクセルの点灯・消灯と色の切り替えだけで動いて見えます。

## 考え方

- 1ボクセル ≈ 15cm。各ボクセルは **持ち主 (entity id) と色を1つだけ** 持つ。
- 世界は水平方向にどこまでも続く。16×16×32 のチャンク単位で、近づいたときに作る。
  地面は平らで、木・岩・木箱・NPC がチャンクごとにシードから決まった場所に置かれる。
- 時間は固定ティック制（1秒に12.5回）。物体は1ティックに最大1ボクセル動く。

### 人型キャラと歩行アニメーション

- 身長14ボクセル（頭4・胴5・脚5）。`src/humanoid.js` で組み立てる。
- 歩くと8コマの周期で手足のボクセルが切り替わる（1周期で8ボクセル ≈ 1.2m 進む）。
  脚は腰、腕は肩を支点に前後に振れ、同じ側の手足は逆向きに動く。止まると立ち姿に戻る。
- 当たり判定は常に **9×14×9 の直方体**。直方体の中の消灯セルもキャラが占有している。
  コマや向き（4方向）が変わっても占有するセルは同じなので、アニメーションで衝突は起きない。

### 衝突（優先度による押し出し）

| 物体 | 優先度 |
| --- | --- |
| 地面・木・岩 | ∞ |
| プレイヤー | 3 |
| NPC | 2 |
| 木箱 | 1 |

- 動く側の優先度が相手より **高い** ときだけ押し出せる。同じか低ければ止まる。
- 押し出しは1段まで（`MAX_PUSH_DEPTH = 1`）。`Infinity` にすると連鎖押し出しになる。
- 移動は「計画 → 一斉に反映」。計画の途中で1つでも失敗したら誰も動かないので、重なりは起きない。
- 処理順はプレイヤー → NPC。NPC はプレイヤーから 80 ボクセル以内のものだけ動く。

## 遊び方

ES モジュールを使うので、ファイルを直接開くのではなくローカルサーバーで開いてください。

```sh
cd voxel-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

- `W` `A` `S` `D` / 矢印キー: 移動（カメラの向き基準）。画面右下のボタンでも操作できる
- ドラッグ: 視点回転、ホイール: ズーム（カメラはプレイヤーを追いかける）
- `Space`: 一時停止、停止中に `.` で1ティック進む
- 「当たり判定を表示」で、動く物の占有範囲を枠で表示

## ファイル

- `src/world.js`: 世界のロジック（描画に依存しない）。チャンク、優先度による押し出し、NPC、地形生成
- `src/humanoid.js`: 人型キャラのボクセル模型と歩行のコマ
- `src/main.js`: three.js での描画と入力。変わったチャンクだけ owner / color を読み直して表示する
- `test/world.test.js`: ロジックのテスト（`npm test`、Node 18 以上）

## まだやっていないこと

- 遠くのチャンクのデータはメモリに残り続ける（描画だけ片付けている）
- 重力・段差・ジャンプ（地面は平ら）
- 斜め移動
