# ボクセル押し出し

世界をボクセルの「ディスプレイ」として扱う 3D ゲームの試作です。
物体はなめらかに動くのではなく、ボクセルの点灯・消灯と色の切り替えだけで動いて見えます。

## 考え方

- 世界は `20 × 6 × 20` のボクセル格子。各ボクセルは **持ち主 (entity id) と色を1つだけ** 持つ。
- 時間は固定ティック制（1秒に8回）。物体は1ティックに最大1マス動く。
- 1つのボクセルに2つの物は入れないので、ぶつかったら **優先度** で決着をつける。

| 物体 | 優先度 |
| --- | --- |
| 壁・床 | ∞ |
| プレイヤー | 3 |
| NPC | 2 |
| 箱・大箱 | 1 |

- 動く側の優先度が相手より **高い** ときだけ押し出せる。同じか低ければ止まる。
- 押し出しは1段まで（`MAX_PUSH_DEPTH = 1`）。箱の後ろに物があると押せない。
  `Infinity` にすると連鎖押し出しになる。
- 移動は「計画 → 一斉に反映」。計画の途中で1つでも失敗したら誰も動かないので、重なりは起きない。
- 処理順はプレイヤー → NPC。

## 遊び方

ES モジュールを使うので、ファイルを直接開くのではなくローカルサーバーで開いてください。

```sh
cd voxel-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

- `W` `A` `S` `D` / 矢印キー: 移動（カメラの向き基準）。画面右下のボタンでも操作できる
- ドラッグ: 視点回転、ホイール: ズーム
- `Space`: 一時停止、停止中に `.` で1ティック進む

## ファイル

- `src/world.js`: 世界のロジック（描画に依存しない）。ボクセル格子、優先度による押し出し、NPC の動き
- `src/main.js`: three.js での描画と入力。`world.cells` / `world.colors` を毎ティック読んで表示する
- `test/world.test.js`: ロジックのテスト（`npm test`、Node 18 以上）
