# ボクセル押し出し

世界をボクセルの「ディスプレイ」として扱う、オープンワールドの 3D ゲームの試作です。
キャラも木箱も、なめらかに動くのではなく、ボクセルの点灯・消灯と色の切り替えだけで動いて見えます。

## 考え方

- 1ボクセル ≈ 15cm。各ボクセルは **持ち主 (entity id) と色を1つだけ** 持つ。
- 世界は水平方向にどこまでも続く。16×16×256（高さ ≈ 38m）のチャンク単位で、近い順に少しずつ作る。
  チャンクは使った高さの分だけメモリを持ち、上に物が来たら継ぎ足す。
  地形・木・岩・木箱・NPC はシードから決まる（同じシードなら同じ世界）。
- 時間は固定ティック制（1秒に25回）。物体は1ティックに最大1ボクセル動く。

### 人型キャラと動き

- 身長15ボクセル（1ボクセル ≈ 15cm）。`src/humanoid.js` で組み立てる。
- 手描きのコマではなく、骨格（腰・膝・足首・肩・肘・首・頭）の角度から体を作る。
  太もも・すね・腕は先細りのカプセル、胸・腰・頭は丸みのある塊として、15cm の粒に塗りつぶす。
  関節は連続的に曲がるが、表示はボクセル単位なのでドット感は残る。
- 動きは `src/character.js`。アニメーションは移動のコマと切り離し、毎ティック（1秒に25回）姿勢から描き直す。
  - 歩く: 振り出す脚の膝が曲がり、腕は同じ側の脚と逆に振れる。骨盤の高さは地面に着いた脚の長さで決まるので、自然に上下する
  - 走る（Shift）: 前傾、大きな腕振り、肘を曲げる、両足が浮く瞬間がある
  - 加速・減速: 歩き出し・止まりは一定の加速度。歩行周期は実際の速さに合わせて進むので、足が滑らない
  - 方向転換: 8方向。体は一定の速さで回り、振り返るときは足を緩める
  - 押す: 木箱を押すと前傾して腕を前に出し、遅くなる。押しても動かないときは踏ん張る
  - 待機: 呼吸で胸と肩が上下し、まばたきし、ときどき首を回して周りを見る。重心も少し揺れる
  - 木や岩にぶつかったら足踏みせずに立ち止まり、道が空いたかだけ確かめる
- 当たり判定は常に同じ形（9×15×9 の箱の中の円柱）。その中の消灯セルもキャラが占有している。
  姿勢や向きが変わっても占有するセルは同じなので、アニメーションで衝突は起きない。
  色が変わったセルだけ書き換えるので、立ち止まっているキャラはほとんど描き直さない。

### 地形

- `src/terrain.js`。なだらかな丘（高低差は最大 7m ほど）に、ところどころ高台や小さな崖（段丘）がある
- 水面の高さは全体で同じ。それより低い所は池になり、川はノイズの等高線に沿って蛇行する谷に流れる
- 色: 地表は草（高い所は乾いた草）、水辺は砂、急な所は岩肌。崖や段差の側面には土の層と、3段ごとに色の違う岩の地層が見える
- 地中のセルもすべて地面が占有するが、外から見えるセル（地表と、隣より高い所の側面）だけ点灯する
- 水は一番弱い（優先度 0）。人が入ると場所をゆずり、出ていけば元に戻る。水面の高さにある人の消灯セルには水面の色が映る。
  水面は半透明で、浅い所は川底が見える
- 人は胸の高さ（9 ボクセル）より深い水には入らない。木箱は足場のない所（水の上や段差の先）へは押せない

### 段差と重力

- 人は 2 段（30cm）までの段差は歩いて登り降りする。登った直後と着地のときは膝を曲げる
- 足元が空けば重力で落ちる（9.8 m/s²）。3 段以上の段差は登れない
- 当たり判定は 9×15×9 の箱の中の円柱。どちらを向いても同じで、斜面でも角が引っかかりにくい

### 木

- `src/trees.js`。キャラと同じく骨格から作る: 根張りのある幹 → 大枝 → 小枝と枝分かれし、
  枝の途中や先に葉の塊がつく。葉の塊は扁平な塊を3〜5個重ね、ノイズで縁を崩し、ところどころ隙間をあける。
  上は明るく下は暗い。中は見えないので空洞（厚さ2ボクセルほどの殻）。
- 種類: ケヤキ（箒状）・カシ（丸い樹冠）・スギ（段ごとに垂れた枝の円錐）・シラカバ（白い幹に黒いすじ）。
  2割ほどは若木。大木は 8〜13m（50〜90 ボクセル）で、キャラよりずっと大きい
- 森と野原は低い周波数のノイズで分かれ、場所によって木の種類の割合も変わる（水辺は広葉樹とシラカバ、高い所はスギが多い）。木は地表に根を張る
- 木はチャンクをまたいで広がる。チャンクを作るとき、そこにかかる木の部分だけを塗る。
  木同士が重なるセルは区画の順で先の木のものになるので、チャンクを作る順番によらず同じ森になる
- 風: 突風が風下へ流れていき、強いところでは葉の塊が風下へ1ボクセルずれる。高い枝ほどよく揺れる。
  幹と枝は動かない。木は「葉がずれうる範囲」まで占有しているので、風で何かとぶつかることはない
- カメラとプレイヤーの間にある、頭より高いボクセル（樹冠など）は消して、プレイヤーが見えるようにする

### 龍

- `src/dragon.js`。東洋の龍で、全長およそ 60m（400 ボクセル）、胴の太さは人の背丈ほど
- 頭が飛んだ道すじ（軌跡）を胴がなぞる。そこに後ろへ流れる波を重ねて S 字にうねらせ、曲がるときは体を傾ける
- 胴は太さの変わる管で、厚さ 2 ボクセルほどの殻（中は空）。上は2色の鱗、背筋に暗い線とのこぎり状の背びれ、下は腹板
- 頭: 長い鼻づら、開いた口と牙、黄色い目と眉、ほおのひれ、枝分かれする角、なびく髭と鬣。短い四肢は泳ぐように掻き、尾の先には炎のような房
- プレイヤーのまわり 9〜16m を大きく回り、ときどき低く降りてくる。先の方の木や丘の高さを見て、ぶつからない高さを保つ
- 龍は空いているセルにしか入らず、何も押し出さない（1つのボクセルには1つの物だけ）。1秒に 12.5 回、前の体を消して新しい体を書く
- 「カメラで龍を追う」で、カメラが龍の胴のなかほどを追う

### 衝突（優先度による押し出し）

| 物体 | 優先度 |
| --- | --- |
| 地面・木・岩 | ∞ |
| プレイヤー | 3 |
| NPC | 2 |
| 木箱 | 1 |

- 動く側の優先度が相手より **高い** ときだけ押し出せる。同じか低ければ止まる。
- 押し出しは1段まで（`MAX_PUSH_DEPTH = 1`）。`Infinity` にすると連鎖押し出しになる。
- 移動は「計画 → 一斉に反映」。計画の途中で1つでも失敗したら誰も動かないので、重なりは起きない。
- 処理順はプレイヤー → NPC。NPC はプレイヤーから 80 ボクセル以内のものだけ動く。

## 遊び方

ES モジュールを使うので、ファイルを直接開くのではなくローカルサーバーで開いてください。

```sh
cd voxel-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

- `W` `A` `S` `D` / 矢印キー: 移動（カメラの向き基準、2つ同時で斜め）。画面右下のボタンでも操作できる
- `Shift`: 走る（画面右下の「走」ボタンで切り替えも可）
- ドラッグ: 視点回転、ホイール: ズーム（カメラはプレイヤーを追いかける）
- `Space`: 一時停止、停止中に `.` で1ティック進む
- 「当たり判定を表示」で、動く物の占有範囲を枠で表示

## ファイル

- `src/world.js`: 世界のロジック（描画に依存しない）。チャンク、優先度による押し出し、NPC、地形生成
- `src/terrain.js`: 地形の高さ・川と池・地面と水の色
- `src/trees.js`: 木の形・配置・風
- `src/dragon.js`: 龍の形と飛び方
- `src/grid.js` / `src/rng.js`: 格子の寸法、乱数とノイズ
- `src/humanoid.js`: 人型キャラの骨格と、姿勢からボクセルへの塗りつぶし
- `src/character.js`: 速度・向き・歩行周期・待機動作などキャラの動き
- `src/main.js`: three.js での描画と入力。ボクセル1つを箱1つで描き、変わったセルの箱だけ書き換える
- `test/world.test.js`: ロジックのテスト（`npm test`、Node 18 以上）

## まだやっていないこと

- 遠くのチャンクのデータはメモリに残り続ける（描画だけ片付けている）
- 隠れて見えないボクセルも描いている（森の中では箱の数が数十万になる）
- ジャンプ、泳ぐ
- 木箱の重力（今は足場のない所へ押せないだけ）
