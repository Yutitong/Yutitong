# ツルピカ丸の大冒険 〜 なみだの きょじん きょうだい 〜

ブラウザで遊べるレトロRPGです。`index.html` をブラウザで開くだけで遊べます（インストール不要）。

## あそびかた

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | 十字ボタン |
| 決定・話す・調べる | Z / Enter / Space | A |
| 取消・メニュー | X / Esc | B / MENU |
| 音のオン・オフ | M | 「♪ 音」ボタン |

- メニューの「きろく」でセーブできます（ブラウザに保存）。タイトルの「つづきから」で再開。
- 宿屋・山の仙人・自宅のふとんで休むと全回復し、全滅したときはそこから再開します（所持金は半分）。

## ストーリー

豆腐屋の主人ツルピカ丸は、今日もあくせく働いた。仕事の疲れをとるため銭湯へ行くと、
そこで激レアモンスター「ラッキアーノ」に出会う。気がつけば周りは異形のものばかり——
裸で外へ飛び出したツルピカ丸は、山を越え、丘を越え、世界の果てで謎の巨人「マタニーニ」と出会う。

- **序章** 絹ごし町・銭湯まんぷく湯
- **第1章 はだかの だっしゅつ** きぬごし平原 → ゆげ山 → まめ丘 → 世界の果て
- **第2章 ニガリ地方へ** おから村（キヌ加入）→ ゆけむり洞窟（ラッキアーノ加入）
- **第3章 なみだの きょうだい** あぶらあげシティ → ワキニーニの城

## なかま

- **ツルピカ丸**：豆腐屋の主人。はじめは「しごとの つかれ」で本来の力が出せない。
- **キヌ**：おから村の湯もみ娘。回復と熱湯の術が得意。
- **ラッキアーノ**：激レアモンスター。運まかせのわざで戦う。

## ファイル構成

- `js/story.js` イベントとセリフ
- `js/maps.js` マップ・NPC・宝箱
- `js/data.js` 仲間・わざ・どうぐ・そうび・モンスター
- `js/battle.js` 戦闘システム
- `js/engine.js` 描画・入力・メニュー・店・宿屋
- `js/sprites.js` ドット絵（文字列ビットマップ）とタイル
- `js/audio.js` チップチューンBGMと効果音（WebAudio）
