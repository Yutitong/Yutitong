# 怪盗館長と幻のサンダル

ブラウザで遊べる短編RPGです。`index.html` をブラウザで開くだけで遊べます（インストール不要）。

## あそびかた
- 移動：矢印キー / WASD / 画面の十字ボタン
- しらべる・はなす・決定：Z / Enter / Aボタン
- メニュー・もどる：X / Esc / Bボタン
- 仮眠室のベッドや光の泉で回復＆セーブ（ブラウザに保存）

## ストーリー
博物館の館長カイトは、裏の顔は窃盗団「よふかし団」の団長。
目的は、鼻緒をちぎれば願いが叶うという幻の遺跡「サンダル」の復活。
警察とボンボミュージアムンQに阻まれながら、光人の母を説得するための花
「テロンテロンサファリウム」を探しに、アメン・ラーメンの門の先へ――。
