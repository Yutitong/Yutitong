# 怪盗館長と幻のサンダル

ブラウザで遊べる、スーファミ風ドット絵の短編RPGです。`index.html` をブラウザで開くだけで遊べます（インストール不要）。

## あそびかた
- 移動：矢印キー / WASD / 画面の十字ボタン
- しらべる・はなす・決定：Z / Enter / Aボタン
- メニュー・もどる：X / Esc / Bボタン
- 仮眠室のベッドや光の泉で回復＆セーブ（ブラウザに保存）

## ストーリー
博物館の館長カイトは、裏の顔は窃盗団「よふかし団」の団長。
目的は、鼻緒をちぎれば願いが叶うという幻の遺跡「サンダル」の復活。
警察とボンボミュージアムンQに阻まれながら、光人の母を説得するための花
「テロンテロンサファリウム」を探しに、アメン・ラーメンの門の先へ――。

## 演出
- 16×24ドットのキャラ（陰影・輪郭線・歩行アニメ）と、後ろをついて歩く仲間
- 「！」「？」「♥」「💢」などのフキダシ、顔グラフィック付きの会話
- 夜の暗さや松明・泉の光、ホタル・花びら・泡などの空気感
- モザイク＋渦巻きのバトル突入、場所ごとの背景、斬撃・魔法エフェクト、ダメージ数字、敵の分解アニメ
- オープニング・オオウナギ・「アレ」・エンディングの一枚絵風演出
- 遺跡の中はクラブ仕様：BGM「Flip it n zip」（`ruins-bgm.mp3`）が流れ、ミラーボール・スポットライト・レーザー・光るダンスフロアが曲のビートに合わせて動く。キャラも踊る
